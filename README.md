# Employee Management System

A full-stack Employee Management System built with React, Spring Boot, and PostgreSQL.

## 🌐 Live Demo

[Open Employee Management System](https://employee-management-frontend-7k5p.onrender.com/)

## 💻 GitHub Repository

https://github.com/Thushar-AR/employee-management-system

## 🛠️ Technologies Used

- React
- Vite
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Neon
- Docker
- Render
- GitHub

## ✨ Features

- Add employees
- View employees
- Update employees
- Delete employees
- PostgreSQL database
- REST API
- Production deployment

## 🏗️ Architecture

React Frontend → Spring Boot REST API → PostgreSQL Database

## 🚀 Deployment

Frontend: Render

Backend: Render

Database: Neon PostgreSQL
